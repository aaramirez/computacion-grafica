# Computación gráfica

Cómo una computadora convierte triángulos en imágenes: transformaciones, cámaras, rasterizado, color, sombreado, texturas, shaders en WebGL y WebGPU, trazado de rayos, curvas y animación, con un renderizador que se escribe desde cero en la página.

**Ver en línea:** https://aaramirez.github.io/computacion-grafica/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
